개인정보처리방침

시행일: 2026-11-23

「바깥소식」 업로드 도구(이하 도구)는 유튜브 채널 @바깥소식-j9t 운영자가 자기 채널에 영상을 올리고 예약하는 데만 쓰는 개인용 도구입니다. 다른 사람은 이 도구를 쓰지 않습니다.

쓰는 정보

  • Google 계정 로그인으로 받은 YouTube API 접근 권한(youtube.upload, youtube.force-ssl) — 운영자 채널에 영상 · 썸네일 · 자막 업로드, 공개 예약, 재생목록 추가, 채널 정보와 업로드 목록 읽기에만 씁니다.
  • YouTube Analytics 읽기 권한(yt-analytics.readonly) — 운영자 채널의 조회 · 시청 시간 통계를 운영자 본인이 보는 데만 씁니다.
  • 로그인 토큰은 운영자 컴퓨터에만 저장하며, 어떤 서버로도 보내거나 다른 사람과 나누지 않습니다.

모으지 않는 정보

도구는 시청자나 다른 사용자의 개인정보를 모으거나 저장하거나 팔지 않습니다.

YouTube API 서비스

도구는 YouTube API 서비스를 씁니다. YouTube 서비스 약관 · Google 개인정보처리방침이 함께 적용됩니다. 접근 권한은 Google 계정 보안 설정에서 언제든 거둘 수 있습니다.
